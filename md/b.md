# شجرة فهم: البلوكشين + البيتكوين + العقود الذكية

> الهدف: صورة ذهنية واضحة + مرجع سريع تتعلم منه

---

## 🧠 الصورة الكبيرة

```
[الإنترنت]
   └── [البلوكشين]
         ├── [البيتكوين]
         ├── [الإيثيريوم]
         │       └── [العقود الذكية]
         └── [تطبيقات أخرى]
```

---

## 1) ما هو البلوكشين؟

```
[البلوكشين]
   ├── تعريف: دفتر حسابات رقمي موزّع
   ├── لا مركزي: لا يوجد مالك واحد
   ├── شفاف: كل العمليات مرئية
   ├── غير قابل للتغيير: لا يمكن التلاعب بالسجلات
   └── يعمل عبر:
         ├── عقد (Nodes)
         ├── كتل (Blocks)
         └── تشفير (Cryptography)
```

### كيف تُبنى الكتل؟

```
[Block]
   ├── بيانات معاملات
   ├── توقيت زمني
   ├── Hash (بصمة)
   └── Hash للكتلة السابقة
```

> كل كتلة مرتبطة بالتي قبلها → سلسلة = Blockchain

---

## 2) البيتكوين (Bitcoin)

```
[Bitcoin]
   ├── نوع: عملة رقمية
   ├── الهدف: نقل المال بدون وسيط
   ├── يعمل فوق: البلوكشين
   └── الخصائص:
         ├── محدود (21 مليون)
         ├── لامركزي
         ├── مقاوم للتلاعب
         └── تحويل عالمي
```

### كيف تتم المعاملة؟

```
[إرسال BTC]
   ├── إنشاء معاملة
   ├── توقيع بالمفتاح الخاص
   ├── بث للشبكة
   ├── تحقق من العقد
   └── إدخال في بلوك جديد
```

---

## 3) التعدين (Mining)

```
[Mining]
   ├── حل مسائل رياضية
   ├── الهدف: إضافة بلوك جديد
   ├── المكافأة: بيتكوين
   └── النتيجة:
         ├── تأمين الشبكة
         └── منع التلاعب
```

---

## 4) الإيثيريوم (Ethereum)

```
[Ethereum]
   ├── مثل البيتكوين لكن أوسع
   ├── يدعم:
   │     └── العقود الذكية
   └── يستخدم:
         └── Gas (رسوم تنفيذ)
```

---

## 5) العقود الذكية (Smart Contracts)

```
[Smart Contract]
   ├── تعريف: كود ينفذ نفسه تلقائيًا
   ├── يعمل على: البلوكشين
   ├── لا يمكن تغييره بعد النشر
   └── يعتمد على:
         └── IF / THEN
```

### مثال بسيط:

```
IF (وصل الدفع)
THEN (أرسل المنتج)
```

لا وسيط
لا ثقة بشرية
فقط كود.

---

## 6) كيف ترتبط الأشياء ببعض؟

```
[Blockchain]
   ├── يخزن البيانات
   │
   ├── [Bitcoin]
   │     └── يستخدمه كـ "نقود"
   │
   └── [Ethereum]
         └── يستخدمه كـ "حاسوب"
                └── يشغل العقود الذكية
```

---

## 7) الفرق الأساسي

| العنصر         | الوظيفة         |
| -------------- | --------------- |
| Blockchain     | البنية (النظام) |
| Bitcoin        | المال           |
| Ethereum       | منصة تشغيل      |
| Smart Contract | منطق التنفيذ    |

---

## 8) تشبيه واقعي سريع

* البلوكشين = طريق سريع
* البيتكوين = سيارة تنقل المال
* الإيثيريوم = مدينة فيها خدمات
* العقد الذكي = آلة بيع ذاتية تعمل لوحدها

---

## خلاصة مركزة

```
Blockchain = أساس
   ↓
Bitcoin = مال رقمي
   ↓
Ethereum = نظام أذكى
   ↓
Smart Contracts = تنفيذ تلقائي
```
